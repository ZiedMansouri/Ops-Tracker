Réinitialisation
Cette action supprime définitivement les données sélectionnées dans Firestore. Il n'existe aucune corbeille — la suppression est irréversible. Un export JSON de sauvegarde est proposé avant (c'est ce fichier qui permet de restituer les données ensuite).
Portée :
Périmètre à réinitialiser :
Seules les tâches et demandes assignées au collaborateur sélectionné seront supprimées. Les autres données (références, journal, réunions) ne sont pas touchées.
